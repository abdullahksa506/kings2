# 📸 صور العرض

حط صور الأعضاء هنا وبتظهر في العرض تلقائياً.

## أسماء الملفات (مهم)

اسم الملف = اسم العضو بالعربي، بأي امتداد صورة:

```
deck/photos/شوكا.jpg      ← العميد (شريحة التعريف)
deck/photos/حكير.jpg      ← شريحة «طرفا النزاع»
deck/photos/طلال.jpg      ← شريحة «طرفا النزاع»
deck/photos/خالد.jpg
deck/photos/هشام.jpg
deck/photos/نواف.jpg
```

الامتدادات المقبولة: `.jpg` · `.jpeg` · `.png` · `.webp`

## كيف تضيف صورة

**من GitHub مباشرة (الأسهل):**
1. افتح المستودع → مجلد `deck/photos`
2. اضغط **Add file** ← **Upload files**
3. ارفع الصورة وسمّها باسم العضو
4. **Commit**

بعدها قل لكلود «حدّث العرض» وبيسحبها ويعيد البناء.

## نصائح للصورة

- **مربّعة** أفضل شي (الصورة تُقص دائرية)
- الوجه في **منتصف** الصورة
- **600×600 بكسل فأعلى** — الصور الصغيرة تطلع مبكسلة
- الصور المخزّنة في التطبيق دقتها 180×320 وتطلع ضعيفة، فأي صورة أوضح منها تفرق كثير

## لو ما حطيت صورة

المولّد يرجع تلقائياً لصورة البروفايل من التطبيق. ولو ما فيه بروفايل، يرسم دائرة بالحرف الأول.
