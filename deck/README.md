# 🎞️ عرض دستور عرش الخميس

مولّد العرض التقديمي (PowerPoint) — كل أرقامه محسوبة من بيانات التطبيق الحقيقية.

## البناء

```bash
cd deck
npm install pptxgenjs      # أول مرة فقط
node fetch-app-photos.js   # اختياري — يسحب صور البروفايل كبديل احتياطي
node gen.js                # ينتج دستور-عرش-الخميس-v12.pptx
```

## الصور

حط صور الأعضاء في `deck/photos/` باسم العضو (`شوكا.jpg` · `حكير.jpg` ...).
التفاصيل في [`photos/README.md`](photos/README.md).

**ترتيب الأولوية لكل صورة:**
1. `deck/photos/<الاسم>.<امتداد>` ← صورك أنت
2. `deck/.cache/app_<الاسم>.jpg` ← صورة البروفايل من التطبيق
3. دائرة رمادية بالحرف الأول

## محتوى العرض (21 شريحة)

| الشرائح | القسم |
|---|---|
| 1-3 | الغلاف · الأعضاء الستة · عميد الدستور |
| 4-12 | الأسباب التاريخية — الرحلة بالأرقام، ذاكرة الطلعات، مسار الملوك، ميول المقيّمين، طرفا النزاع، خريطة العداوة |
| 13-16 | الوضع الحالي — الترتيب، دليل الحرب، فجوة المشاركة |
| 17-20 | المواد الأربع (12-15) والنتيجة قبل/بعد |
| 21 | الخلاصة |
